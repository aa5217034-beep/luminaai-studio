# LuminaAI Studio

A self-contained browser photo tool for image upscaling and enhancement. It supports JPG, PNG, and WebP uploads, 2K–16K output modes, canvas-based enhancement, format selection, and local downloads.

## Run locally

```bash
python3 -m http.server 4173
```

Open `http://localhost:4173`.

There is no build step or server-side dependency. The app processes images locally in the browser.
